# 证据与真实性规则

## 来源分层

| 状态 | 使用方式 |
|---|---|
| 已核实 | 已读到支持该主张的官方文件、原始研究或原始材料，可作为确定依据 |
| 用户提供，未独立核实 | 可按用户材料使用，注明来源属性；不称为已独立验证 |
| 仅确认题录或摘要 | 仅使用可见内容，不声称已读全文，不扩写其结论 |
| 待核实 | 标注“[待核实：具体内容]”，不得进入确定性结论 |
| 拟采集 | 用未来语态写采集计划，不写成已有结果 |

## 操作要求

1. 为关键主张记录来源、年份、页码或章节、链接或文献标识和支持范围。
2. 优先核验官方申报文件、原始研究和原始数据。二手来源不得冒充原始来源。
3. 核对政策名称、发布机构、日期与适用范围。不能仅凭模型记忆确认当前政策或申报要求。
4. 核对作者、题名、年份、载体和可查标识；无法确认时提出检索词或证据需求，不补造题录。
5. 数据需记录时间、样本、口径及计算方式。不得用计划样本替代实际样本，或用示例数值冒充调查结果。
6. 前期论文、项目、平台、合作单位、人员和权限只能来自已提供或核实材料。缺失时使用“[待补充：真实材料]”。
7. 示例材料标注为示例。保护受访者和学生隐私，不把敏感原始资料写入公开成果。
8. 无检索能力时继续概念和结构工作，列出待验证主张，说明尚未完成文献核验。
9. 区分依据、推断和建议，不把政策要求直接当作某个机制已被证实的证据。
